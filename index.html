TokenPFS

Локальная фабрика токенов для ИИ-моделей. Выбери одну из 42 моделей, скачай одной командой и генерируй ответы на своём железе: на телефоне в Termux или на сервере. Несколько моделей работают параллельно, а скорость подбирается под твоё устройство.

Что умеет TokenPFS


Каждая функция — отдельный модуль по слоям: core → utils → modules.




/models
Каталог из 42 моделей
Llama, Qwen, Phi, Gemma, DeepSeek, Mistral, Mixtral: от лёгких 0.4 ГБ до тяжёлых более 16 ГБ. Свободное место проверяется до скачивания.


/dl
Скачивание с подтверждением
Спрашивает «Download? Y/n», показывает прогресс-бар и присваивает готовой модели номер: [01], [02]…


/w
Вопросы моделям
/w [номер/имя] [текст] — ответ генерируется локально и выводится как [модель] - ответ [время] [токены].


/stf
Ручная скорость
Ограничь число токенов в секунду, чтобы телефон или сервер не перегревался.


/autt
Автоподбор
Замеряет CPU, RAM и диск, считает POWER SCORE и рекомендует, сколько токенов в секунду потянет устройство.


/jobs
Параллельная работа
Спрашивай вторую, третью, пятую модель одновременно. Дашборд показывает статус каждой.


live
Статус генерации
Во время ответа видно строку: модель, что делает, tok/s и через сколько будет готово.


/dnm
Свои модели
Загружай любые GGUF-модели из репозиториев GitHub и HuggingFace. Им тоже присваивается номер.


/dnmf
Локальные файлы
Подключай уже скачанные .gguf с устройства. Удаление: /delm [имя/номер].

Установка


Нужен только терминал. Скрипт определит систему, поставит Python, Git и Ollama, скачает TokenPFS и добавит команду tokenpfs.


🧭 v2.0.0-alpha — поддержка платформ: 🪟 Windows (нативный install.ps1, без WSL) · 🍎 macOS (Intel/Apple Silicon) · ☁️ VPS/облако (headless по SSH под root, без sudo, автоопределение виртуализации в /autt) · 🐧 Linux / 📱 Termux














Автоустановка в одну команду


Ставит зависимости, клонирует репозиторий, запускает Ollama и создаёт команду tokenpfs.


curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash


После установки


  1. Открой новый терминал (или выполни source ~/.bashrc) и запусти tokenpfs.
  2. Программа проверит железо и предложит модель (/autt).
  3. Дальше: /models → /dl 01 → /w 01 вопрос.


Ручная установка, если не доверяешь curl | bash

# Debian / Ubuntu
sudo apt update && sudo apt install -y python3 git curl
# Fedora / RHEL
sudo dnf install -y python3 git curl
# Arch
sudo pacman -S --noconfirm python git curl

# Ollama
curl -fsSL https://ollama.com/install.sh | sh
systemctl --user enable --now ollama 2>/dev/null || ollama serve &

# TokenPFS
git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS && python3 tokenpfs_app.py







Termux (Android)


  1. Установи Termux из F-Droid. Версия из Play Market устарела.
  2. Вставь команду автоустановки:


curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash


  1. Запусти tokenpfs (после source ~/.bashrc или нового сеанса).
  2. Включи Acquire wakelock в уведомлении Termux, чтобы генерация не останавливалась при блокировке экрана.
  3. На слабых телефонах бери лёгкие модели (0.5B–1.5B) и /autt для подбора tok/s.


Вручную по шагам

pkg update && pkg install python git ollama -y
ollama serve &
git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS && python3 tokenpfs_app.py







Windows 10/11


v2.0.0-alpha: появился нативный установщик для Windows — WSL больше не обязателен. Открой PowerShell.


Способ A: автоустановка одной командой (рекомендуется)


iwr -useb https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.ps1 | iex


Скрипт сам поставит Python и Git через winget, скачает официальный OllamaSetup.exe (тихая установка), клонирует TokenPFS в %USERPROFILE%\.tokenpfs\TokenPFS и добавит команду tokenpfs. После этого открой новый терминал и выполни tokenpfs.


Способ B: WSL2 (если предпочитаешь Linux-окружение)


wsl --install -d Ubuntu


После перезагрузки открой Ubuntu и выполни автоустановку:


curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash


Запуск из терминала Ubuntu: tokenpfs. Ollama доступен и из Windows по адресу http://localhost:11434.


Способ C: чистый Python вручную


  1. Установи Ollama для Windows (.exe).
  2. Установи Python 3.10+ с галочкой «Add to PATH».
  3. В PowerShell выполни:


git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS
python tokenpfs_app.py







macOS (Intel / Apple Silicon)


На Apple Silicon Ollama ускоряется через Metal без настройки. Открой Терминал.


Автоустановка (нужен Homebrew)


curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash


Вручную


brew install ollama python git
brew services start ollama
git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS && python3 tokenpfs_app.py


Нет Homebrew? Поставь его с brew.sh или скачай Ollama.app и выполни ручные команды без brew.







Модель считает сервер, интерфейс у тебя


Если мощная машина с GPU есть в сети, а TokenPFS ты запускаешь на телефоне или ноутбуке.


1. На сервере


curl -fsSL https://ollama.com/install.sh | sh
OLLAMA_HOST=0.0.0.0:11434 ollama serve


2. На клиенте (любая ОС)


TOKENPFS_OLLAMA_URL=http://192.168.1.50:11434 tokenpfs


Все генерации идут на сервер, локально остаются интерфейс и логи. Проверка связи: curl http://192.168.1.50:11434/api/tags должен вернуть JSON.





Без Ollama: программа запустится в DEMO-режиме. Можно изучить интерфейс и команды, но ответы будут фиктивными.







Команды


Все команды вводятся прямо в программе. Список всегда под рукой: /help.




КомандаЧто делает


/modelsКаталог всех 42 моделей с номерами и размерами


/dl [номер/имя]Скачать модель с подтверждением Y/n и прогрессом


/w [модель] [текст]Задать вопрос модели; несколько вопросов разным моделям идут параллельно


/stf [число]Сколько токенов в секунду вырабатывать (0.1–1000)


/auttЗамер мощности железа, POWER SCORE и рекомендация tok/s


/dnm [ссылка]Загрузить свою модель с GitHub или HuggingFace (.gguf)


/dnmf [путь]Подключить локальный файл модели


/delm [имя/номер]Удалить модель из списка


/jobsСтатус всех текущих генераций


/statusСостояние Ollama и скачанных моделей


/helpСписок команд в терминале


quitВыход после завершения незаконченных ответов









FAQ


Это бесплатно?
Да. Модели считаются локально через Ollama: без облака, подписок и лимитов провайдера.


Потянет ли обычный телефон?
Да, лёгкие модели (0.4–2 ГБ). Запусти /autt: программа оценит железо и подскажет безопасную скорость.


Можно ли говорить с несколькими моделями сразу?
Да, в этом суть проекта. Каждый /w запускает отдельный поток, а дашборд показывает прогресс всех генераций.


Что если модель не помещается на SSD?
Перед скачиванием тяжёлой модели (более 16 ГБ) TokenPFS проверит свободное место и предупредит заранее.


Где хранятся модели?
В стандартном каталоге Ollama. Реестр номеров лежит в ~/.tokenpfs/models.json.
