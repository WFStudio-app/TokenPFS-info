TokenPFS

Локальная фабрика токенов для ИИ-моделей. Выбери одну из 42 моделей, скачай её одной командой и генерируй ответы прямо на своём железе — хоть на телефоне в Termux, хоть на сервере. Несколько моделей работают параллельно, скорость генерации подбирается автоматически под твоё устройство.

✨ Что умеет TokenPFS

Каждая функция — отдельный модуль по слоям: core → utils → modules.

🧰

Каталог из 42 моделей

Llama, Qwen, Phi, Gemma, DeepSeek, Mistral, Mixtral… от лёгких 0.4 ГБ до тяжёлых >16 ГБ (проверка свободного места перед скачиванием).

📥

Download [модель]? Y/n

После выбора модели появляется окно подтверждения, затем живой прогресс-бар загрузки. Готовой модели сразу присваивается номер [01], [02]…

💬

Вопросы /w

/w [номер/имя модели] [текст] — модель генерирует ответ локально. Ответ оформляется так: > [модель] - [ответ] [время] [токены].

🎛️

Скорость /stf

/stf [токенов в секунду] — вручную ограничиваешь потребление, чтобы телефон или сервер не перегревался.

🧠

Автоподбор /autt

Замеряет мощность железа (CPU/RAM/disk), считает POWER SCORE и сам рекомендует, сколько токенов в секунду потянет устройство.

🔀

Параллельная работа

Одновременно можно задать вопрос второй, третьей, пятой модели — все генерируют параллельно, а live-дашборд показывает статус каждой.

📊

Live-статус генерации

Во время ответа видно строку:
[модель] [что делает] [tok/s] [через сколько готова] — без ожидания вслепую.

🐙

Свои модели /dnm

/dnm [ссылка на GitHub/HuggingFace] — загружай любые GGUF-модели из репозиториев, им тоже присваивается номер.

📁

Локальные файлы /dnmf

/dnmf [путь к файлу .gguf] — подключай уже скачанные модели с устройства. Удаление — /delm [имя/номер].

🚀 Установка

Выбери свою платформу выше — команды подставятся автоматически. Нужен только терминал: скрипт сам определит систему, установит Python, Git и Ollama, скачает TokenPFS и добавит команду запуска tokenpfs.

⚡ Один клик — автоустановка

Просто вставь эту команду в терминал — она делает всё: ставит зависимости, клонирует репозиторий, запускает Ollama и создаёт команду tokenpfs:

curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash

🧭 Что произойдёт после установки

  1. Открой новый терминал (или выполни source ~/.bashrc) и запусти: tokenpfs
  2. Программа сама проверит железо и предложит модель под него (/autt).
  3. Дальше по меню: /models → /dl 01 → /w 01 вопрос.
🔧 Ручная установка (если не доверяешь curl | bash) 
# Debian / Ubuntu
sudo apt update && sudo apt install -y python3 git curl

# Fedora / RHEL
sudo dnf install -y python3 git curl

# Arch
sudo pacman -S --noconfirm python git curl

# Ollama
curl -fsSL https://ollama.com/install.sh | sh
systemctl --user enable --now ollama 2>/dev/null || ollama serve &

# TokenPFS
git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS && python3 tokenpfs_app.py

📱 Termux (Android)

  1. Установи Termux из F-Droid (не из Play Market — там устаревшая версия).
  2. Вставь одну команду — автоустановщик сам поставит Python, Git и Ollama:
curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash
  1. Запусти: tokenpfs (после source ~/.bashrc или нового сеанса Termux).
  2. Совет: включи Acquire wakelock в уведомлении Termux, чтобы генерация не останавливалась при блокировке экрана.
  3. На слабых телефонах используй лёгкие модели (0.5B–1.5B) и /autt для подбора tok/s.
🔧 Вручную по шагам 
pkg update && pkg install python git ollama -y
ollama serve &
git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS && python3 tokenpfs_app.py

🪟 Windows 10/11

TokenPFS работает через WSL2 (рекомендуется) или напрямую с Python. Открой PowerShell:

Способ A — WSL2 (рекомендуется)

wsl --install -d Ubuntu

После перезагрузки открой «Ubuntu» и выполни одну команду автоустановки:

curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash

Запуск из Ubuntu-терминала: tokenpfs. Можно также открыть сайт из WSL по адресу http://localhost:11434 — Ollama доступен и из Windows.

Способ B — чистый Python без WSL

  1. Установи Ollama для Windows (обычный .exe-инсталлятор).
  2. Установи Python 3.10+ (галочка «Add to PATH»). Официального apt/pkg в Windows нет — это единственный ручной путь.
  3. Открой PowerShell и выполни:
git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS
python tokenpfs_app.py

🍎 macOS (Intel / Apple Silicon)

Apple Silicon — идеальная платформа: Metal ускоряет Ollama «из коробки». Открой Терминал:

Автоустановка (нужен Homebrew)

curl -fsSL https://raw.githubusercontent.com/WFStudio-app/TokenPFS/main/scripts/install.sh | bash

Или вручную

brew install ollama python git
brew services start ollama
git clone https://github.com/WFStudio-app/TokenPFS.git
cd TokenPFS && python3 tokenpfs_app.py

Нет Homebrew? Установи его одной командой с brew.sh, либо просто скачай Ollama.app перетаскиванием в Applications и выполни ручные команды без brew.

🌍 Модель считает сервер, интерфейс у тебя

Если мощная машина с GPU есть в сети, а TokenPFS ты хочешь запустить на телефоне или ноутбуке:

1. На сервере

curl -fsSL https://ollama.com/install.sh | sh
OLLAMA_HOST=0.0.0.0:11434 ollama serve

2. На клиенте (любая ОС)

TOKENPFS_OLLAMA_URL=http://192.168.1.50:11434 tokenpfs

Все генерации идут на сервер, локально только интерфейс и логи. Проверить связь: curl http://192.168.1.50:11434/api/tags должен вернуть JSON.

🧪 Без Ollama

Если Ollama недоступен, программа запускается в DEMO-режиме — можно изучить весь интерфейс и команды, но ответы будут фиктивными.

❓ FAQ

Это бесплатно?

Да. Модели считаются локально через Ollama — ни облака, ни подписок, ни лимитов провайдера.

Потянет ли обычный телефон?

Да, лёгкие модели (0.4–2 ГБ). Запусти /autt — программа сама оценит железо и подскажет безопасную скорость генерации.

Можно ли говорить с несколькими моделями сразу?

Да — это ядро проекта. Каждый /w запускает отдельный поток; дашборд показывает прогресс всех генераций одновременно.

Что если модель не помещается на SSD?

Перед скачиванием тяжёлой модели (>16 ГБ) TokenPFS проверяет свободное место и предупреждает заранее.

Где хранятся модели?

В стандартном каталоге Ollama; реестр номеров — ~/.tokenpfs/models.json.
